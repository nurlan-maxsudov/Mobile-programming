# Model assets

This folder contains the supplied Teachable Machine **Floating point / TensorFlow Lite** export:

- `model_unquant.tflite`
- `labels.txt` (at least six named classes, one indexed label per line)
- `sample.jpeg` (the bottle photo used for the Part 3 smoke test)

Labels: Nothing, Bottle, Phone, Glasses, Mouse, Card. Replace model and labels
together when retraining. This folder is declared in `pubspec.yaml`.
