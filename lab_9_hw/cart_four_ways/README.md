# One Cart, Four Ways

Lab 9 shopping cart using setState, Riverpod, Cubit and Bloc.

```sh
flutter pub get
flutter analyze
flutter test
flutter run -d web-server --web-hostname 127.0.0.1 --web-port 8080
```

Open http://127.0.0.1:8080 and select a style. Add products, use +/-, apply
SAVE10, checkout and undo. The fake checkout declines totals above 500.

See [NOTES.md](NOTES.md) for the lab answers, code comparison and demo flow.
Git commits, tags and pushing are left to the student.
